# Code of conduct

Focus Diff follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, and keep discussions about the work.

Report unacceptable behaviour to the maintainer through [GitHub's private reporting](https://github.com/hyanmandian/focus-diff/security/advisories/new) or by [reporting the content to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam). Reports are kept confidential.
