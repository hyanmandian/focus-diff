# Bookshelf

Track what you read, organize books into shelves and share reviews.

- `web/`: React app, one folder per feature under `src/features`, shared UI under `src/ui`.
- `api/`: FastAPI service, one package per domain under `bookshelf/`, tests under `tests/`.
- `docs/`: product and engineering notes.

This app is a sample used to demo Focus Diff on a large pull request.
