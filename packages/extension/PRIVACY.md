# Privacy policy

Focus Diff does not collect, sell, or share any data. It sends nothing to its developer or to anyone but GitHub.

- **Signing in:** you connect Focus Diff to GitHub once, with a code you enter on github.com (GitHub's device flow) or a personal access token you paste. The token is kept in the browser's local storage on this device, is sent only to `https://api.github.com`, and never reaches the pages: they ask the extension's background for GitHub's data and it makes the calls. Disconnecting in Settings deletes it.
- **What it stores, on this device only (the browser's local storage):** the token; your setup (queues, filters, review times, actions, theme, language), as the Mac app keeps it in its config file; your review pace as it learns it; your queues' pull requests as last read from GitHub and what you've seen or taken off them, to tell what's new; notifications kept for review time; the last copy of each review you opened (removed after two weeks unused); comments for your pending review and viewed marks still on their way to GitHub, until GitHub takes them; and the filter you last picked on each repository. Nothing is synced between devices.
- **Where it runs:** its own pages (the toolbar popup, Settings, setup and the review tabs), and on `https://github.com/*`, where its bar reads the file paths, line counts and viewed marks already shown on a pull request's files to hide files and update the counters. Nothing it reads there leaves your browser.
- **What it asks GitHub:** while you're signed in, it reads the pull requests in your queues from GitHub's API, as often as you set in Settings (every minute by default), and the pull requests you open to review: their files, conversations, checks and logs, commits and the files' contents. What you do in a review (comments, reviews, viewed marks, merging, labels, reviewers) is sent to GitHub's API as you do it. People's pictures load from `https://avatars.githubusercontent.com`, and pictures in comments from GitHub, with the session already in your browser. Signed out, it makes no requests.
- **Your review pace:** on a pull request's files, it counts the time you're active on each file until you mark it viewed, and keeps only running totals per kind of file (code, tests, docs and so on) on the device. It never records which files or pull requests, and it sends nothing.
- **Permissions:** `storage`, to keep your setup and the token; `unlimitedStorage` (Chrome), so your queues and reviews fit; `alarms`, to look at GitHub on your queues' rhythm and keep your review times; `notifications`, to tell you what's new in your queues and when a review time starts; access to `https://api.github.com` (GitHub's API) and `https://github.com` (signing in with a code, and the bar on pull requests).
- **Third parties:** none. GitHub is the only site it talks to.
