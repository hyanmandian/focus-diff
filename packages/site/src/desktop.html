Questions

Do I need the GitHub CLI?

No. If gh is installed and signed in, the app uses it. Otherwise paste a personal access token, which stays in your system’s keychain.

Does the AI cost anything?

Not from Focus Diff. It runs the Claude Code or Cursor command line you already use, on your own plan, and only when you ask it something. Without one, everything else works the same.

Why does my computer warn me the first time?

The app isn’t code-signed yet, so the system asks once. On a Mac, open it, then go to System Settings › Privacy & Security and click Open Anyway (on macOS 14 and earlier, right-click the app and choose Open). On Windows, choose More info, then Run anyway.

How does it update?

It checks for a new version every few hours. When there is one, the panel shows an Update button: one click downloads it, checks its signature, installs it and restarts. That’s the Mac, Windows and AppImage versions; the .deb and .rpm update by installing the new package.
