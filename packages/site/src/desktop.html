Opening it the first time.

The app isn’t signed by Apple or Microsoft yet, so your system asks once. After that, updates install from the app’s Update button.

macOS 15 and later.

  1. Open Focus-Diff.dmg, click Agree and drag Focus Diff to Applications.
  2. Eject the disk image and open Focus Diff from Applications. When macOS says it couldn’t verify the app, click Done, not Move to Trash.
  3. Go to System Settings › Privacy & Security, scroll down to Security and click Open Anyway next to “Focus Diff.app” was blocked.
  4. Click Open Anyway once more and confirm with Touch ID or your password.

On macOS 14 and earlier, right-click Focus Diff in Applications and choose Open.

No Open Anyway, or a Mac your company manages? Paste this in Terminal instead. It installs the same app, in your own Applications folder when you can’t write to the main one, with nothing to approve:

curl -fsSL https://focus-diff.com/install.sh | sh

The script checks the download against the release’s SHA256SUMS, and its build provenance too when the GitHub CLI is signed in, then clears the app’s quarantine flag, which skips Gatekeeper because the app isn’t notarized yet. How it’s checked

Windows 10 and 11.

  1. Run Focus-Diff-Setup.exe. It installs for your user, without asking for an administrator.
  2. When Windows says it protected your PC, click More info, then Run anyway.

No Run anyway, or a PC your company manages? Paste this in PowerShell instead. It installs the same app for your user, with nothing to approve:

irm https://focus-diff.com/install.ps1 | iex

The script checks the download against the release’s SHA256SUMS, and its build provenance too when the GitHub CLI is signed in. How it’s checked

Nothing to approve on Linux. Use either one:

  • The AppImage, which updates itself:
    chmod +x Focus-Diff.AppImage && ./Focus-Diff.AppImage
  • The .deb or the .rpm, updated by installing the next one:
    sudo apt install ./Focus-Diff.deb

Questions

Do I need the GitHub CLI?

No. If gh is installed and signed in, the app uses it. Otherwise paste a personal access token, which stays in your system’s keychain.

Does the AI cost anything?

Not from Focus Diff. It runs the Claude Code, Codex, Cursor or OpenCode command line you already use, on your own plan, and only when you ask it something. Without one, everything else works the same.

Why does my computer warn me the first time?

The app isn’t code-signed yet, so the system asks once. On a Mac, open it, then go to System Settings › Privacy & Security and click Open Anyway (on macOS 14 and earlier, right-click the app and choose Open). On Windows, choose More info, then Run anyway. Step by step.

How does it update?

It checks for a new version every few hours. When there is one, the panel shows an Update button: one click downloads it, checks its signature, installs it and restarts. That’s the Mac, Windows and AppImage versions; the .deb and .rpm update by installing the new package.
