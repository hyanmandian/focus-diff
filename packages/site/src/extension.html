Install it yourself.

Every release comes with ready-made builds. Download one and load it into your browser, no store needed.

Chrome, Edge, Brave, Arc, Opera and every other Chromium browser.

  1. Unzip focus-diff-chromium.zip.
  2. Open chrome://extensions (edge://extensions in Edge) and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.

It doesn’t update itself. The Chrome Web Store version does.

Download for Chromium

Firefox, Zen, LibreWolf, Floorp and other browsers built on Firefox.

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on and pick focus-diff-firefox.zip.

It stays until Firefox restarts. The Firefox Add-ons version stays for good, and updates itself.

Download for Firefox

Safari on a Mac with Xcode.

  1. Unzip focus-diff-safari.zip, run this in Terminal, then click Run in Xcode: 
    xcrun safari-web-extension-converter focus-diff-safari --app-name "Focus Diff" --macos-only
  2. In Safari, turn on Settings › Advanced › Show features for web developers, then Develop › Allow Unsigned Extensions.
  3. Turn on Focus Diff in Settings › Extensions. Safari asks again for unsigned extensions after it restarts.

Questions

Does it send my code anywhere?

No. It collects no data and sends nothing to anyone but GitHub. Your filters stay in your browser’s storage.

Does it work on private repositories?

Yes. It works on any pull request you can open on github.com, public or private, with the session already in your browser.

Which browsers does it support?

Chrome, Edge, Brave, Arc, Opera and other Chromium browsers, Firefox and the browsers built on it, and Safari on a Mac.

Does it need my GitHub password or a token?

No. It works with the GitHub session already in your browser, like opening the pages yourself.
