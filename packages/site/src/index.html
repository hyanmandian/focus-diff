Private by default.

Focus Diff has no account and no server. It talks to GitHub directly, with the sign-in you already have.

  • No account. No sign-up, and nothing to set up on your repositories.
  • Nothing but GitHub. There’s no server of ours for your code to go to. The one exception is the AI you choose to run in the desktop app.
  • No tracking. No analytics and no tracking cookies, on this site or in the apps.
  • Open source. MIT licensed, so every line can be checked. Read the privacy policy.

Questions

Is it free?

Yes. The extension and the desktop app are free and open source under the MIT license.

The extension or the desktop app?

The extension if you like reviewing on github.com: it makes each pull request page easier to work through. The desktop app if you’d rather not open GitHub at all. Use either, or both.

Does it send my code anywhere?

No. Focus Diff has no account and no server. It talks to GitHub with your own sign-in. The one exception is the desktop app’s AI, which runs your own Claude Code, Codex, Cursor or OpenCode, only when you ask it something.

Does it work on private repositories?

Yes. Both work on any pull request your GitHub account can open.

Does it work with GitLab or Bitbucket?

Not yet. It works on GitHub today.
