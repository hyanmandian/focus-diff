Focus Diff

A browser extension for GitHub pull requests. Filter the diff to the files you care about, see how much is left to review, and step through every conversation without hunting for it.

Review a big pull request one part at a time

Focus Diff adds a small bar to the Files changed page of every GitHub pull request. It works from what the page already shows: no account, no setup on the repository.

  • Filters from file paths

    Each filter is a button with an Include and an optional Exclude regex, tested against the full path. Keep them for every repository, or add some for one repository or one owner.

  • Counters that count again

    Files changed and the added and removed lines show only what the filter keeps, so you see the real size of your review before you start.

  • Review time left

    An estimate next to the line totals, from about 1,000 changed lines an hour, that drops as you mark files as viewed, until it says Done.

  • A breakdown by filter

    Every filter side by side: how many of its files you’ve viewed, the lines they change and the time they take.

  • The next file to review

    One click, or Alt Shift J, takes you to the next file you haven’t viewed, then on to the next filter that has some.

  • Every conversation, one by one

    Step through the review threads, each with its file and line, and see which are waiting on you, answered or resolved.

  • Made to share

    Copy your filters and send them to a teammate, who imports them in one step. Themes for the bar are shared the same way.

  • Private by design

    No account, no tracking and no network requests. Focus Diff reads the file paths and line counts on the page, and nothing leaves your browser.

Install it yourself

Every release comes with ready-made builds. Download one and load it straight into your browser, no store needed.

Chrome, Edge, Brave, Arc, Opera and every other Chromium browser.

  1. Unzip focus-diff-chromium.zip.
  2. Open chrome://extensions (edge://extensions in Edge) and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
Download for Chromium

Firefox, Zen, LibreWolf, Floorp and other browsers built on Firefox.

  1. Open about:debugging#/runtime/this-firefox.
  2. Click Load Temporary Add-on and pick focus-diff-firefox.zip.

It stays until Firefox restarts. The store version stays for good.

Download for Firefox

Safari on a Mac with Xcode.

  1. Unzip focus-diff-safari.zip, run this in Terminal, then click Run in Xcode: 
    xcrun safari-web-extension-converter focus-diff-safari --app-name "Focus Diff" --macos-only
  2. In Safari, turn on Settings › Advanced › Show features for web developers, then Develop › Allow Unsigned Extensions.
  3. Turn on Focus Diff in Settings › Extensions. Safari asks again for unsigned extensions after it restarts.

Questions about Focus Diff

Does it send my code anywhere?
No. It makes no network requests and collects no data. Your filters stay in your browser’s storage.
Does it work on private repositories?
Yes. It works on any pull request page you can open on github.com, public or private, using only what that page shows you.
Which browsers does it support?
Chrome, Edge, Brave, Arc, Opera and other Chromium browsers, Firefox and the browsers built on it, and Safari on a Mac.
Does it work with GitLab or Bitbucket?
Not yet. It works on GitHub today, and it’s built so other code review sites can be added.
Is it free?
Yes. Focus Diff is free and open source under the MIT license, and its code is on GitHub.
