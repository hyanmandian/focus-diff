How filters match files

A file is shown when its path matches Include and doesn't match Exclude. Both are JavaScript regular expressions, tested against the full path (for example src/components/Button.tsx) and not case-sensitive. An empty Include matches every path.

\.(ts|tsx)$
TypeScript files
\.(test|spec|stories)\.
tests and stories, as an Exclude
^packages/api/
everything under one folder
(^|/)tests?/
any test/ or tests/ folder

All is always available and shows every file.
